4 Defense-in-Depth Safety Layers (policy.py)
L1
Local Allow-List & Consent Gate
Mandates authorized_confirmed=true and http(s) only. Permits localhost, 127.0.0.1, ::1 & RFC1918; blocks all public hosts (403).
L2
Pre-Request DNS & Anti-Rebinding
Resolves hostnames via socket.getaddrinfo() before connect — unconditionally blocking public IPs & cloud metadata 169.254.169.254.
L3
Manual Same-Origin Redirect Guard
Runs allow_redirects=False and validates 3xx Location headers manually (<= 5 same-origin hops), never following external redirects.
L4
Destructive Denylist & Budgets
Skips /logout, /delete, /reset & /purge to protect local state. Enforces 10 req/s throttle, 2,000 cap, 10s timeout & <= 5s cancel.

Cooperative Cancellation (≤ 5s Halt)threading.Event
  • Immediate Ack (200 OK): POST /api/scans/{id}/cancel sets thread-safe threading.Event on the active worker immediately.
  • Graceful <= 5s Halt: Crawler & checks poll cancel_event between probes, preserving partial findings and emitting SSE scan_cancelled.

  • Per-Check try/except: A ReadTimeout, malformed HTML, or runtime error inside one plugin never aborts the scan.
  • Non-Fatal Telemetry: Orchestrator logs the fault, emits SSE check_warning badge & continues all remaining OWASP checks.
